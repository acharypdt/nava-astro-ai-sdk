# Contributing to NavaAstro AI SDK

Thank you for considering contributing! We welcome contributions from the community.

## How to Contribute

1. **Fork** the repository
2. **Create a feature branch**: `git checkout -b feature/my-feature`
3. **Commit** your changes: `git commit -am 'Add my feature'`
4. **Push** to the branch: `git push origin feature/my-feature`
5. **Open a Pull Request**

## Development Setup

```bash
npm install
npm run dev
```

## Code Style

- TypeScript strict mode
- No commented code
- Follow existing patterns in the codebase
- Use Hindi for UI text, English for code/comments

## Pull Request Guidelines

- Keep PRs focused on a single concern
- Add tests if applicable
- Update documentation if needed
- Ensure `npm run build` passes

## Reporting Issues

Use the GitHub issue tracker: <https://github.com/nava-astro-ai-sdk/nava-astro-ai-sdk/issues>
